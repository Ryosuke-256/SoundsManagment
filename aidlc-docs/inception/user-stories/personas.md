# User Personas: Sound Sample Manager (音源管理ソフト)

## Overview
本ドキュメントでは、音源管理ソフトの主要な利用者像（ペルソナ）を定義し、ユーザーの目標、作業環境、課題、および機能要件へのマッピングを明確化します。

---

## Persona 1: ケンタ (Kenta) — トラックメイカー / サウンドコレクター

```
+-----------------------------------------------------------------------+
| ケンタ (27歳) - トラックメイカー / ビートメイカー                     |
| 主なジャンル: Drum & Bass, Trap, Lo-Fi HipHop, Synthwave              |
| 使用環境: Windows 11, Cakewalk by BandLab, Sonar                      |
| サンプル保有数: 20,000ファイル以上（BandLab Sounds, 各種Sample Pack） |
+-----------------------------------------------------------------------+
```

### プロフィール & 背景
- BandLab SoundsやWeb上の無料・有料サンプルパックを日常的に大量ダウンロードしている。
- 音源ファイルがPC内の複数フォルダやダウンロードフォルダに散乱しており、整理に時間を取られている。

### 目標 & ニーズ (Goals)
- ダウンロードしたフォルダ（`Loop/`, `Oneshot/` 等）をソフトに投入するだけで、ファイル名からBPM・キー・楽器・パック名を自動判別して整然と管理フォルダへ整理してほしい。
- 判別できなかった音源は安全に「Other」タグ・フォルダに隔離され、後から手動で確認・タグ付けできる状態にしたい。
- データベースが破損せず、PCを再起動しても安定して継続利用できるライブラリ環境を維持したい。

### 課題 & ストレス要因 (Frustrations)
- エクスプローラーの階層を手作業で整理するのが困難。
- パックごとにファイル名のフォーマットが異なり、どれが何の楽器か分からない。

## Persona 2: ユウキ (Yuuki) — 作曲家 / アレンジャー

```
+-----------------------------------------------------------------------+
| ユウキ (32歳) - コンポーザー / アレンジャー                           |
| 主な制作内容: ゲーム音楽・劇伴・ポップス編曲                          |
| 使用環境: Windows 11, Cakewalk by BandLab, Sonar (メインDAW)          |
| 制作スタイル: デュアルディスプレイでDAWと音源マネージャーを並べて配置 |
+-----------------------------------------------------------------------+
```

### プロフィール & 背景
- クライアントワークでタイトな納期に対応しており、楽曲のBPMやキー（調性）に合致するフレーズや音色をいかに速く探し出せるかが制作スピードを左右する。

### 目標 & ニーズ (Goals)
- 制作中の楽曲テンポ（例: `174 BPM`）やキー（例: `D minor`）を指定して、1秒未満で候補のLoopやワンショットを一覧表示したい。
- 上下矢印キーでリストを選択するだけで即座に自動試聴再生（Auto-Play）され、波形（Waveform）を見ながら欲しい部分を確認したい。
- 気に入った音源が見つかったら、そのままマウスでドラッグしてCakewalk / Sonarのオーディオトラックへ直接ドロップして貼り付けたい。

### 課題 & ストレス要因 (Frustrations)
- DAW標準のメディアブラウザは検索・絞り込みが弱く、BPMやキーでの絞り込みができない。
- プレビュー再生のレイテンシー（遅延）があると、制作のリズムやインスピレーションが途切れる。

## ペルソナと主要機能のマッピング

| 機能領域 | ケンタ (ライブラリ・DB管理重視) | ユウキ (制作・DAW連携重視) |
|---|---|---|
| **音源インポート & 自動整理** | 高（ワンクリックで整理済みフォルダへ配置） | 中（既存ライブラリの利用が主） |
| **「Other」フォールバック分類** | 高（未分類音源を後から手動タグ付け） | 中（未分類音源も検索から除外されずアクセス可能） |
| **ファセット検索 & ソート** | 中（タグの整合性確認） | 最高（BPM/Key/楽器で瞬時に絞り込み） |
| **波形表示 & 高速プレビュー** | 中（音の確認） | 最高（Auto-Play / ループ再生で高速試聴） |
| **DAWドラッグ＆ドロップ** | 中（配置テスト） | 最高（Cakewalk / Sonarへ直接配置） |
| **DBバックアップ & 堅牢性** | 最高（蓄積したライブラリの保護） | 高（制作中のクラッシュ回避） |
