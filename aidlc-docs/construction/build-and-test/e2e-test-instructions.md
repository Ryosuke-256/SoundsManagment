# E2E（エンドツーエンド）および手動動作確認手順書（E2E Test Instructions）

## 1. 目的
音楽制作者および DAW ユーザーの実際のワークフロー（音源のインポート、検索、波形試聴、BPM・キー解析、Cakewalk by BandLab / Sonar への配置）に沿った手動 E2E 動作確認手順を定めます。

---

## 2. E2E 実機動作確認シナリオ

### シナリオ 1: 初回起動および管理ライブラリの自動初期化
1. アプリケーションを起動します：
   ```powershell
   python src/main.py
   ```
2. DAW に調和するダークテーマのメイン画面（左: フィルタ、中央: テーブル、下部: 波形プレイヤー）が表示されることを確認。
3. アプリケーション実行フォルダ配下に `SoundLibrary/` フォルダ（`Database/`, `Library/Loop/`, `Library/Oneshot/`, `Library/Other/`, `Backups/`）が自動生成されていることを確認。

### シナリオ 2: BandLab 音源パックのフォルダ一括インポート
1. メニュー **File -> Import Folder...**（またはツールバーのインポートボタン）をクリック。
2. サンプル音源が入ったフォルダ（`Loop` フォルダや `Oneshot` フォルダなど）を選択。
3. ステータスバーに進捗バーが表示され、解析およびインポートが進行することを確認。
4. 完了ダイアログに「スキャン数」「インポート数」「重複リネーム数」「Other分類数」が正しく集計されることを確認。
5. テーブルに音源が追加され、楽器・ジャンル・BPM・キーが自動分類されていることを確認。

### シナリオ 3: 高速ファセット検索・波形描画・ループ試聴
1. 検索バーにキーワード（例: "Kick" や "Guitar"）を入力（200ms デバウンスで瞬時に絞り込み）。
2. タイプ（`Loop` / `Oneshot` / `Other`）チェックボックスや BPM 範囲スピンボックスで絞り込み。
3. テーブルの任意の行をシングルクリック：
   - 下部にアンチエイリアス波形が瞬時に描画されることを確認。
   - **Auto-Play: ON** の場合、即座に試聴再生が開始されることを確認。
4. 波形表示エリアをクリックして再生ヘッドが追従シークすることを確認。
5. **Loop: ON** に設定した場合、音源終端到達時にシームレスに先頭からループ再生されることを確認。

### シナリオ 4: Cakewalk / Sonar / Studio One への直接ドラッグ＆ドロップ
1. DAW（Cakewalk by BandLab または Sonar）を起動し、プロジェクトのオーディオトラックを表示。
2. 音源管理ソフトのテーブルから任意の音源行をドラッグし、Cakewalk のトラック上へドロップ。
3. DAW 側のドロップ位置にオーディオクリップが配置され、DAW 上で正常に再生できることを確認。

### シナリオ 5: Story 2.4 / FR-2.5 定量音声解析および命名規則自動リネーム
1. BPM やキーが未設定の音源（または `Other` 分類の音源）を選択。
2. メニュー **Tools -> Audio Signal Analyzer & Auto-Rename (Story 2.4)...** を開く。
3. **▶ Start Audio Analysis** をクリックし、Onset / Chroma 解析による BPM および調性推定が実行されることを確認。
4. 新ファイル名（`[BaseName]_[BPM]BPM_[Key].[ext]`）の差分プレビューを確認。
5. **✓ Apply Rename & Update DB** をクリックし、実ファイルのリネームとデータベースの更新が正常に完了することを確認。

### シナリオ 6: 安全な2段階削除（BR-107 / BR-404）
1. テーブルの任意の音源行を右クリック：
   - **Remove from Library**: 確認ダイアログで「Yes」を選択 -> データベースから登録解除され、実ファイルはディスクに残ることを確認。
   - **Move to Recycle Bin**: 確認ダイアログで「Yes」を選択 -> 実ファイルが Windows ごみ箱へ安全に移動され、データベースからも削除されることを確認。
